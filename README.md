# Blow Your Power

เกมเป่าลมเพื่อฟื้นฟูปอด 3 มิติ ผู้เล่นเป่าลมใส่ไมโครโฟน ปอดบนหน้าจอจะค่อยๆ ฟื้นฟู
เมื่อเป่าต่อเนื่องครบ 8 วินาทีถือว่าสำเร็จ จากนั้นเกมจะประเมินผลและเชื่อมกับข้อมูลทางการแพทย์

> ผลประเมินเป็นการประเมินเบื้องต้นเพื่อความสนุกและการเรียนรู้ ไม่ใช่การวินิจฉัยโรค
> ไมโครโฟนวัดค่า FEV1/FVC ไม่ได้

## ฟีเจอร์

- **หน้าแรก:** เป่าลมใส่ไมค์ ปอดฟื้นฟูตามแรงเป่า จบรอบแล้วแสดงคะแนน 0–100 พร้อมคำแนะนำ
- **เรียนรู้:** ดูปอด หลอดลม ถุงลมแบบ 3 มิติ (หมุนดูได้) และอ่านข้อมูลการแพทย์ที่เกี่ยวข้อง
- **บริหารปอด:** ฝึก 3 ท่า คือ เป่าลมแบบห่อปาก, หายใจด้วยกะบังลม, เป่ายาว
- ปอด ต้นไม้ และเงา สร้างจากโค้ดทั้งหมด (Three.js) ไม่ใช้ไฟล์โมเดลสำเร็จรูป

## ทำงานอย่างไร

```
ไมค์ → server.py (Python, 30 ครั้ง/วินาที) → WebSocket (JSON) → React → ปอด 3D (Three.js)
                                                                    ↓
                                                  ผลประเมิน + ข้อมูลการแพทย์
```

- `server.py` จับเสียงจากไมค์ (นับเฉพาะเสียงต่ำกว่า 400 Hz ซึ่งเป็นเสียงลมเป่า) ปรับค่าเกณฑ์อัตโนมัติ
  แล้วคุมสถานะเกม IDLE → PLAY → PAUSE → REWIND → DONE
- หน้าเว็บ (`client/`) รับสถานะทาง WebSocket แล้วแสดงปอด 3 มิติและผลประเมิน

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `server.py` | เซิร์ฟเวอร์ไมค์ + เกม + WebSocket (ไลบรารีมาตรฐานของ Python) |
| `client/src/App.jsx` | หน้าหลัก รวมทุกส่วนเข้าด้วยกัน |
| `client/src/hooks/useBreathing.js` | เชื่อม WebSocket และตัวประเมินผลแต่ละรอบ |
| `client/src/hooks/useExercise.js` | ท่าบริหารปอด |
| `client/src/lib/attemptTracker.js` | เก็บระดับเสียงตลอดรอบการเป่า |
| `client/src/lib/blowAssessment.js` | เกณฑ์คะแนน ข้อความผลลัพธ์ และแหล่งอ้างอิงทางการแพทย์ |
| `client/src/lib/sound.js` | เสียงประกอบเกม |
| `client/src/components/Lungs.jsx`, `lungModel.js`, `lungFoliage.js` | ปอดและต้นไม้ 3 มิติ |
| `main.py` | เวอร์ชันแรก (Pygame + OpenCV เล่นวิดีโอตามแรงเป่า) ไม่ได้ใช้แล้ว |
| `test_ws_sender.py` | สคริปต์จำลองข้อมูลการหายใจ สำหรับทดสอบ |

## วิธีรัน

ต้องมี Python 3.12 และ Node.js 18 ขึ้นไป

### 1) เซิร์ฟเวอร์

```bash
pip install -r requirements.txt
python server.py --demo      # ไม่ต้องมีไมค์ (กด Space ค้างในหน้าเว็บแทนการเป่า)
python server.py             # ใช้ไมค์จริง
```

ตัวเลือกที่ใช้บ่อย: `--duration 8` (วินาทีที่ต้องเป่า), `--threshold 0.02` (ข้ามการปรับไมค์),
`--debug` (แสดงกราฟสัญญาณ), `--device` (เลือกไมค์)

### 2) หน้าเว็บ (เปิดอีกหน้าต่าง Terminal)

```bash
cd client
npm install
npm run dev
```

ค่าเริ่มต้นเว็บจะต่อกับเซิร์ฟเวอร์ที่ `VITE_BACKEND_URL` ถ้าเซิร์ฟเวอร์รันในเครื่องเดียวกัน ให้ตั้งเป็น `http://localhost:8080`

- Windows PowerShell: `$env:VITE_BACKEND_URL="http://localhost:8080"; npm run dev`
- macOS / Linux: `VITE_BACKEND_URL=http://localhost:8080 npm run dev`

จากนั้นเปิด <http://localhost:5173>

### หรือใช้ Docker (โหมดเดโม ไม่ต้องมีไมค์)

```bash
docker compose up --build
```

เปิด <http://localhost:5173>

## ข้อมูลการแพทย์ที่อ้างอิง

- การฝึกหายใจผ่านวิดีโอเกมเทียบกับการฝึกแบบปกติในเด็กหลอดลมพอง (ERS Congress, บทคัดย่อ PA354)
- มาตรฐานการวัดสมรรถภาพปอด (สไปโรเมทรี) ATS/ERS 2019
- ผลกระทบของมลพิษทางอากาศต่อการทำงานของปอด (ทบทวนวรรณกรรมเชิงระบบ 27 งานวิจัย)

รายละเอียดและลิงก์อยู่ในหน้า "เรียนรู้" → "การแพทย์" และในไฟล์ `client/src/lib/blowAssessment.js`
เกณฑ์คะแนน (เช่น เป้าหมาย 8 วินาที) เป็นค่าที่ทีมตั้งเอง ไม่ได้มาจากมาตรฐานทางการแพทย์
